# TapeDog

**Find the favorites worth fading.**

College football trap-game radar. TapeDog scores FBS favorites from **0–99** using situational signals, betting markets, and AI-powered scouting reports.

### Features
- **Fade Board:** Ranked trap games and saved picks
- **Game Files:** Odds, line movement, FPI, Kalshi, weather, news, and AI analysis
- **TapeDog Plus:** Coming soon

### Tech
ESPN · Action Network · Kalshi · Open-Meteo · Gemini AI · Vercel

Free public APIs with server-side caching.
